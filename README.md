# 🎯 7주차 - Roulette
## 프로젝트 소개
마우스 입력을 기반으로 룰렛을 회전시키고 감속시키는 Unity 프로젝트입니다.  
회전 속도 제어와 방향 전환, 입력 이벤트 처리 등을 중심으로 구현했습니다.

## 구현 내용
- 마우스 휠 클릭 시 룰렛 회전
- 마우스 왼쪽 클릭 시 룰렛 감속 및 정지
- 마우스 오른쪽 버튼을 누르는 동안 지속 회전
- 버튼을 떼면 서서히 감속
- 룰렛 회전 방향 반전
- 룰렛 바늘 위치 변경

## 학습 내용
- 마우스 입력 처리
- 오브젝트 회전 제어
- 감속 애니메이션 구현
- Unity Transform 활용
<br>

# 🚗 8주차 - SwipeCar
## 프로젝트 소개
자동차를 이동시켜 목적지까지 도달하는 Unity 프로젝트입니다.  
UI 시스템과 이동 로직, 지형 처리 등을 중심으로 구현했습니다.

## 구현 내용
- 자동차 이동 구현
- 거리 표시 UI 구현
- UI 문구 한글화
- 평지를 비탈길 형태로 수정
- 자동차가 경사면을 따라 자연스럽게 이동하도록 구현

## 학습 내용
- Unity UI(Text, Canvas, EventSystem)
- Rect Transform 활용
- 거리 계산 및 UI 갱신
- 지형 기울기 기반 이동 처리
- GameDirector를 활용한 UI 관리 구조
<br>

# 🐱 9주차 - CatEscape

## 프로젝트 소개
플레이어가 좌우로 이동하며 위에서 떨어지는 화살을 피하는 2D 회피 게임입니다.  
프리팹, 충돌 판정, 오브젝트 생성 시스템 등을 학습하며 제작했습니다.

## 구현 내용
- 플레이어 좌우 이동
- 키보드 화살표 입력 지원
- 스마트폰 플레이를 위한 좌우 버튼 추가
- 화살 생성 시스템 구현
- 시간에 따라 화살 낙하 속도 증가
- 충돌 판정 구현
- HP UI 구현
- 플레이어가 화면 밖으로 벗어나지 않도록 제한

## 학습 내용
- PlayerController / ArrowController 구조 설계
- Prefab 및 Generator 패턴 활용
- 충돌 판정 알고리즘 구현
- UI 갱신 시스템 구현
- 모바일 환경 대응
- 동적 난이도 증가 시스템 구현
<br>
