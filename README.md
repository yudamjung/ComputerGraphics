# 🎯 7주차 - Roulette
## 프로젝트 소개
마우스 입력을 기반으로 룰렛을 회전시키고 감속시키는 Unity 프로젝트입니다.  
회전 속도 제어와 방향 전환, 입력 이벤트 처리 등을 중심으로 구현했습니다.

## 구현 내용
- 마우스 휠 클릭 시 룰렛 회전
- 마우스 왼쪽 클릭 시 룰렛 감속 및 정지
- 마우스 오른쪽 버튼을 누르는 동안 지속 회전
- 버튼을 떼면 서서히 감속
- 룰렛 회전 방향 반전
- 룰렛 바늘 위치 변경

## 학습 내용
- 마우스 입력 처리
- 오브젝트 회전 제어
- 감속 애니메이션 구현
- Unity Transform 활용
<br>

# ☁️ 10주차 - ClimbCloud

## 프로젝트 소개
플레이어가 계속 오른쪽으로 자동 이동하며 점프하여 올라가는 게임입니다.  
점프 메커닉, 애니메이션 시스템, 물리 엔진을 활용한 게임 구현을 학습했습니다.

## 구현 내용
- 자동 우측 이동 (walkForce로 제어)
- 마우스/스페이스바 점프 메커닉 (jumpForce 적용)
- 플립북 방식의 걷기 애니메이션 (0.1초마다 프레임 전환)
- 점프 중 별도 점프 스프라이트 표시
- 바닥 충돌 판정 (isGrounded 체크)
- 화면 하단 넘어가면 게임 재시작
- 깃발 오브젝트 접촉 시 클리어

## 학습 내용
- Rigidbody2D를 활용한 2D 물리 시뮬레이션
- AddForce를 이용한 이동 및 점프 구현
- 충돌 감지 (OnCollisionEnter2D, OnTriggerEnter2D)
- 플립북 애니메이션 구현
- 씬 로드 및 게임 상태 관리
<br>

# 🌰 11주차 - Bamsongi

## 프로젝트 소개
마우스 클릭으로 발사체(햄버거/밤송이)를 발사하는 3D 슈팅 게임입니다.  
Ray casting을 이용한 정조준, 3D 물리 엔진, 파티클 이펙트를 활용했습니다.

## 구현 내용
- 마우스 클릭으로 발사체 생성 (Instantiate)
- Camera.ScreenPointToRay를 이용한 정조준
- Ray 방향 × 2000의 힘으로 발사 (AddForce)
- 발사체 충돌 시 Rigidbody isKinematic = true로 중력 무효화
- 충돌 시 ParticleSystem 실행으로 폭발 이펙트
- 3D 물리 기반 발사체 운동

## 학습 내용
- Raycasting을 이용한 3D 정조준 시스템
- Rigidbody 3D 물리 구현
- AddForce로 발사체 속도 제어
- 충돌 감지 (OnCollisionEnter)
- Instantiate를 통한 동적 오브젝트 생성
- 파티클 시스템 활용
<br>

# 🍎 12주차 - AppleCatch

## 프로젝트 소개
30초 동안 떨어지는 사과를 받고 폭탄을 피하는 캐주얼 게임입니다.  
시간에 따른 동적 난이도 조절, 오디오 시스템, 점수 계산을 구현했습니다.

## 구현 내용
- 30초 카운트다운 타이머
- 마우스 클릭으로 바구니 위치 이동 (Raycast hit point 기반)
- 사과 수집 시 +100점, 폭탄 접촉 시 점수 /100 (감소)
- 시간대별 난이도 동적 조절:
  - 0~5초: 생성 주기 0.9초, 속도 -0.04, 폭탄 확률 3/10
  - 5~10초: 생성 주기 0.4초, 속도 -0.06, 폭탄 확률 6/10 (가장 어려움)
  - 10~20초: 생성 주기 0.7초, 속도 -0.04, 폭탄 확률 4/10
  - 20~30초: 생성 주기 1.0초, 속도 -0.03, 폭탄 확률 2/10
- 아이템 무작위 생성 (Random.Range로 위치 결정)
- 사과/폭탄별 효과음 재생 (AudioClip)
- TextMeshPro UI로 타이머 및 점수 표시

## 학습 내용
- GameDirector 패턴으로 게임 상태 관리
- 시간 경과에 따른 난이도 동적 조절
- Random.Range를 이용한 무작위 생성
- 확률 기반 아이템 선택 로직
- Raycast를 이용한 3D 위치 이동
- 오디오 시스템 (PlayOneShot)
- UI 갱신 시스템 (TextMeshPro)
