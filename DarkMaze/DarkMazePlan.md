## 🗺️ 씬 구성

총 3개의 씬으로 구성된다.

### 1. 설명 씬 (Intro Scene)
- 게임 조작법과 목표를 텍스트로 안내
- 분위기에 맞는 어두운 배경
- "시작하기" 버튼으로 게임 씬으로 전환

### 2. 게임 씬 (Game Scene)
- 실제 미로 탈출 플레이
- 상세 내용은 아래 참고

### 3. 성공 씬 (Success Scene)
- 탈출 성공 시 전환
- 축하 메시지 + 클리어 타임 표시
- "다시 하기" 버튼

> 씬 전환 시 **페이드 인/아웃 효과** 적용

## 🏰 미로 구조 — 3구역 레벨 설계

미로는 하나이며, 내부를 3개의 구역으로 나눈다.

```
[입구] ─── 구역 1 ─── 구역 2 ─── 구역 3 ─── [출구]
           (탐색)      (긴장)      (공포)
```

### 구역 1 — 탐색 구간
- 귀신 없음
- 플레이어가 조작에 익숙해지는 구간
- 분위기: 고요하고 불안한 적막

### 구역 2 — 긴장 구간
- 귀신 1마리 순찰
- 걸으면 감지 안 됨, 뛰면 감지됨
- 이동속도 감소를 처음 경험하는 구간

### 구역 3 — 공포 구간
- 귀신 2마리 순찰 (최대 3마리)
- 뛰면 복수의 귀신이 동시에 반응
- 타이머 압박 + 이동속도 감소로 극한의 긴장감

## 🎨 픽셀 에셋 제작 기준

> ⚠️ 모든 에셋은 **90도 탑다운 시점 기준**으로 제작할 것
> 아이소메트릭(45도 쿼터뷰) 스타일 절대 금지

### 전체 비주얼 무드
- 어두운 돌 던전 / 지하 감옥 분위기
- 컬러 팔레트: 어두운 회색, 갈색, 검정 위주 + 핏자국 붉은색 포인트
- 녹슨 철창, 균열 간 돌바닥, 이끼 낀 벽 질감

### 필요 에셋 목록

#### 타일셋 (16×16 or 32×32px, 90도 탑다운)
- [ ] 바닥 타일 — 균열 있는 돌바닥 (어두운 회색)
- [ ] 벽 타일 — 두꺼운 돌벽 (위에서 내려다본 형태)
- [ ] 장식 타일 — 핏자국, 이끼, 균열 (바닥 위에 얹히는 레이어)

#### 오브젝트
- [ ] 입구 문 — 열린 상태 (90도 탑다운, 위에서 본 형태)
- [ ] 출구 문 — 녹색 빛이 은은하게 나는 철창 문
- [ ] 구역 경계 표시 (선택) — 바닥 색 변화나 균열선으로 구분

#### 캐릭터 (4방향 스프라이트)
- [ ] 플레이어 — 위/아래/좌/우 걷기 애니메이션 (각 2~4프레임)
- [ ] 플레이어 — 뛰기 애니메이션 (걷기보다 빠른 프레임)
- [ ] 귀신 — 위/아래/좌/우 순찰 애니메이션
- [ ] 귀신 — 감지 상태 (빨간 눈 등 시각적 변화)

#### UI
- [ ] 타이머 프레임 — 호러 분위기에 맞는 픽셀 테두리
- [ ] 타이머 숫자 폰트 — 픽셀 스타일

## 👻 귀신 AI 로직

### 상태 머신

```
[순찰 상태]
    │
    ▼ 감지 범위 내 소리 감지
[추적 상태] ──── 범위 벗어남 ────▶ [순찰 상태로 복귀]
    │
    ▼ 플레이어와 접촉
[속도 감소 적용]
```

### 소리 감지 범위

| 플레이어 상태 | 발소리 크기 | 귀신 감지 반경 |
|-------------|-----------|-------------|
| 정지 | 없음 | 반응 안 함 |
| 걷기 | 작음 | 약 3타일 |
| 뛰기 | 큼 | 약 7타일 |

### 이동속도 감소 로직

- 귀신 1마리 접촉: 이동속도 **30% 감소**
- 귀신 2마리 동시 접촉: 이동속도 **60% 감소**
- 귀신 3마리 동시 접촉: 이동속도 **80% 감소**
- 귀신 감지 범위에서 **완전히 벗어나면 즉시 원상복구**

## 🔋 추가 레벨 디자인 방향 (토론 결과, 2026-06-16)

### 손전등 배터리 메카닉

기존 시야(Light2D)를 "손전등"으로 재해석하고 배터리 자원 개념을 추가한다.

| 상태 | 시야 반경 | 추가 효과 |
|------|----------|----------|
| 배터리 충분 (100~30%) | 기존 그대로 (걷기 4.5 / 뛰기 6타일) | 없음 |
| 배터리 부족 (30~0%) | 점점 줄어듦 | 손전등 깜빡임 + 소음 발생 → 주변 귀신 반응 |
| 배터리 방전 (0%) | 약 1~1.5타일 (완전 암전은 아님) | 없음 (이미 위험 상태) |

- 배터리 게이지 UI를 타이머 옆 또는 화면 한쪽에 표시 (HP 게이지 아님 — 허용)
- **배터리 아이템**을 미로 내 손으로 배치 → 이것이 이 게임의 핵심 레벨 디자인
  - 배터리 아이템은 어둠 속에서도 은은하게 빛나서 보임
  - 위험 구역(귀신 근처, 막다른 골목) 배치 시 리스크/리워드 발생
- **배터리 부족 시 소음**이 귀신 감지 시스템과 연동됨 (종 역할 흡수)

### 내러티브 텍스트 팝업

특정 이벤트 발생 시 화면에 짧은 한국어 텍스트가 페이드인/아웃으로 표시됨.
반복 가능한 이벤트는 첫 발생 시 1회만 표시.

| 트리거 | 텍스트 예시 |
|--------|-----------|
| 배터리 30% 이하 | "배터리가 얼마 남지 않았다..." |
| 배터리 깜빡임 시작 | "오 이런, 손전등이 꺼질 것 같아..!" |
| 배터리 방전 | "아무것도 보이지 않는다..!" |
| 배터리 아이템 획득 | "다행이다..!" |
| 귀신 첫 접촉 (1회만) | "뭔가 스치고 지나갔다... 발이 무거워진다" |

### 탈출 실패 씬 추가

타임아웃 시 인트로로 바로 돌아가는 대신 별도 실패 씬을 추가.

- "탈출 실패" 메시지
- 소요 시간 또는 도달 거리 표시
- "다시 도전" 버튼 → Game 씬으로 직행
- "처음으로" 버튼 → Intro 씬

기존 Success 씬 구조(SceneButton + ClearTimeLabel 패턴)를 그대로 복사해서 만들 수 있음.

## 🔋 배터리 메카닉 구현 계획 (미구현, 추후 작업)

### 확정된 수치

| 항목 | 값 |
|---|---|
| 시작 배터리 | 15% |
| 소모 속도 | 1%/초 |
| 내러티브 텍스트 트리거 | 25% 이하 (최초 1회) |
| 깜빡임 + 귀신 경보 시작 | 10% 이하 |
| 방전 시 최소 시야 반경 | 약 1~1.5타일 (완전 암전 아님) |
| 배터리 아이템 획득 시 | 100% 복구 |

- 깜빡임 효과음은 Inspector에서 선택적으로 연결 (없으면 시각 깜빡임 + 귀신 경보만 작동)
- 배터리 아이템은 어둠 속에서도 은은하게 빛나야 함 (직접 Light2D 부착 또는 발광 머티리얼)

### 구현해야 할 것 (순서대로)

1. **FlashlightBattery.cs** — 15% 시작, 1%/초 소모, 10% 이하 깜빡임 + 주변 귀신 경보, 0%에서 최소 시야 고정, 픽업 시 100% 복구
2. **PlayerVision.cs 수정** — 배터리 레벨을 시야 반경 계산에 반영 (방전 시 최소값으로 클램프)
3. **BatteryGaugeUI.cs** — 타이머 옆 배터리 게이지 UI (HP 게이지 아님)
4. **NarrativeText.cs** — 이벤트 기반 텍스트 팝업, 코루틴 페이드 인/아웃, 반복 이벤트는 1회만 표시
5. **BatteryPickup.cs** — OnTriggerEnter2D → FlashlightBattery.Restore(100), 발광 시각 처리
6. **씬 배치** — 배터리 아이템 위치 수동 결정 (귀신 근처 or 막다른 골목 → 리스크/리워드)

### 귀신 경보 연동 방식

FlashlightBattery가 깜빡임 상태일 때 일정 간격으로 `GhostAI` 인스턴스를 반경 탐색해서 강제로 Chase 상태로 전환. GhostAI에 `public void ForceChase()` 메서드 추가 필요.
